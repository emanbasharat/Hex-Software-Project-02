# Hex Software Internship — Project 02

## Contact Management System (C++)

### Project Description
A console-based application developed in C++ to manage contact details. This project helps beginners practice programming concepts, data structures, and file handling.

### Features
- Add new contacts
- View all contacts
- Search contacts by name
- Update contact details
- Delete contacts
- Save contact information in a file

### Contact Information
Each contact contains:
- Name
- Phone Number
- Email Address

### Technologies Used
- C++
- Structures
- Vectors
- Functions
- File Handling
- Menu-Driven Programming

### How to Run
1. Open the project in Visual Studio Code.
2. Compile the C++ source file using a C++ compiler.
3. Run the program in the terminal.
4. Select an option from the menu.
